# 學習資源 (Resources)

此目錄用於存放學習資源，包括：
- 參考文件 (Reference Documents)
- 教材 (Learning Materials)
- 工具與軟體清單 (Tools and Software)
- 有用的連結 (Useful Links)

## 資源組織方式 (Organization)
建議按資源類型分類，例如：
```
resources/
├── books/          # 書籍推薦
├── tutorials/      # 教學資源
├── tools/          # 工具介紹
└── links.md        # 有用的連結
```
